# Criptografia em Símbolos

Projeto front-end em HTML, CSS e JavaScript para gerar uma senha e um texto em símbolos, com explicação passo a passo da lógica da criptografia.

## Como abrir

1. Abra o arquivo `index.html` no navegador.
2. Digite uma senha.
3. Escreva sua mensagem secreta.
4. Clique em "Criptografar".
5. Veja o resultado e a explicação detalhada.

## Estrutura

- `index.html` — interface principal
- `styles.css` — visual e layout do site
- `script.js` — lógica de criptografia e descriptografia

## Observação

Este é um exemplo educacional de criptografia visual, pensado para demonstrar o processo de deslocamento e transformação em símbolos.
